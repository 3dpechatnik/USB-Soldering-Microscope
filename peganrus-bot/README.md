# Подземелье и Горынычи — @peganrus_bot

Текстовая D&D 5e RPG с AI-Мастером (DeepSeek). Два Telegram-бота в одном процессе:
игровой (`BOT_TOKEN`) и админ-бот (`ADMIN_BOT_TOKEN`). Режим polling, без webhook.

## Первый запуск на Windows

1. Установите Python 3.14 и PostgreSQL. Создайте базу (один раз):
   ```
   psql -U postgres -c "CREATE DATABASE peganrus_db;"
   ```
2. В папке проекта:
   ```
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните (токены, ключ DeepSeek, `DATABASE_URL`).
4. **`ADMIN_TELEGRAM_ID`**: оставьте `0`, запустите бота и напишите что угодно админ-боту —
   он ответит вашим Telegram ID. Впишите его в `.env` и перезапустите.
5. Запуск:
   ```
   py -m app.main
   ```
   При старте автоматически применяются миграции и добавляются стартовые данные
   (`AUTO_MIGRATE=true`). Остановка — `Ctrl+C`.

Вручную: `alembic upgrade head`, затем `py -m app.db.seed`.

## Где что менять

| Что | Где |
|---|---|
| Токены, лимиты (`LIMIT_TRIAL`, `DAILY_LIMIT_PAID`), цена, время задач планировщика, антифлуд, длина сообщений | `.env` (полный список — в `app/config.py`) |
| Модель, temperature, max_tokens, длина истории, порог сжатия | админ-бот → 🤖 AI (читается из БД при каждом запросе) |
| Игровой промпт и подмодули (бой, отдых, торговля, создание персонажа) | админ-бот → 🧩 Модули (можно загрузить `.txt` файлом) |
| Тексты политики, справки, приветствия, промпт сжатия и анализа, напоминание Мастеру | админ-бот → 🧩 Модули (тип `manual`) |

`game_prompt.txt` — начальное содержимое модуля `base`. Подгружается в БД только если модуля
ещё нет; дальше источник правды — БД (редактируйте через админ-бот).

## Как это работает

- Контекст: `system` (модули `always` + активные триггеры) → строка `[ПЕРСОНАЖ: ...]`
  (+ краткое содержание) → последние N сообщений → новое сообщение. Системный промпт
  одинаков для всех игроков, поэтому кэш DeepSeek работает.
- ИИ вызывает `update_state` и `finalize_character_creation`; код применяет изменения
  к БД с ограничением значений. Запасной вариант — блок `[STATE]{json}[/STATE]` в тексте.
- Когда накопится `compression_threshold` сообщений, история сжимается в резюме, а старые
  сообщения архивируются (текст стирается, строка с токенами остаётся ради статистики).
- Планировщик: 00:05 истечение подписок, 12:00 напоминание за 3 дня
  (без списания), 23:55 дневная статистика в `game_analytics`.
- Оплата: разовая, 100 ₽ на 7 дней, через Robokassa. Автосписаний нет.
  Статус платежа бот спрашивает у Робокассы сам, отдельный домен не нужен.

## Админ-бот

`/start` или `/menu` — главное меню. Также: `/analyze` (кайдзен-анализ через DeepSeek с
кнопками «Применить настройку»), `/user <telegram_id>`, `/cancel`.

## Структура

```
app/
  config.py            настройки из .env
  main.py              запуск обоих ботов + планировщика
  db/                  модели, CRUD, стартовые данные
  bot/                 игровой бот (middleware, хэндлеры, tools для DeepSeek)
  ai/                  клиент DeepSeek, сборка контекста, сжатие, применение состояния
  admin/               админ-бот
  payments/            Robokassa (заглушка)
  scheduler/           задачи по расписанию
alembic/               миграции
```
